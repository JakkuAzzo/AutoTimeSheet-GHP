These silent videos use training examples, show the cursor and highlight each control. Their on-screen prompts are part of the recording; open a text transcript below for a screen-reader-friendly version. Nothing shown in a video is sent to accounts.

All seven workflows are for signed-in staff. Administrator-only user management remains on the dashboard.

Using your portal profile

Review your GMT sign-in identity, display name and optional email for copies.

Read the transcript
  1. Sign in with the GMT Microsoft 365 account issued to you. The portal opens after Microsoft verifies the account.
  2. Confirm your full name. The staff portal reuses it in forms.
  3. Check your GMT login email. Microsoft supplies this identity; it is read-only here.
  4. Add an optional personal email for submission copies. It is saved to your GMT app profile and follows your sign-in on other devices. It does not change mailbox forwarding.
  5. Choose Save account settings when you want to save your changes.

Clock, lunch, absence and whole day

Use the Dashboard clock card for one event, an absence or a complete day.

Read the transcript
  1. Clock in, lunch events and clock out are on the Dashboard. This example does not submit anything.
  2. Confirm your name. Your portal profile normally fills it in.
  3. Choose the event you are recording: Clock in, Lunch start, Lunch end, Clock out, Absent, or + for a complete day.
  4. Check the date and time. They are set automatically and can be changed when needed.
  5. For an absence, choose Absent and select the reason. An absence does not need a time.
  6. For a complete day, use + and enter Start, Lunch start, Lunch end and Finish. Add a note only when it gives Accounts useful context.
  7. Review the details before submitting a live record. The training example leaves the submit button untouched.

Weekly timesheet

Generate weekday cards, enter actual times and review the calculated totals.

Read the transcript
  1. Your GMT sign-in supplies your name and email. The current pay-month period is shown automatically.
  2. Generate weekday cards for the dates shown. Include weekends only when you worked them or need to record an absence.
  3. Check each date and enter the actual Start, Finish and Break. Any values shown in this training example are samples; use your actual times.
  4. Choose an absence reason before entering time for a Sick or Holiday day.
  5. Review each daily result and the calculated totals. Use Analyse or upload an existing timesheet to open the separate timesheet checker.
  6. Review the completed form before submitting. The training example does not submit a timesheet.

Job card

Choose the EC or MTA format, then enter enough detail for the job to be identified.

Read the transcript
  1. Use one clear GMT job reference. The example reference is synthetic and is not a real job.
  2. Choose EC or MTA, then enter the client and site details.
  3. Add the assigned engineer and planned date when known.
  4. Attach an optional photo only when it helps explain the site or work.
  5. Describe the request, access notes, parts and risks. Review the live preview before submitting a real card.
  6. The training example leaves the Create job card button untouched.

Task request

Provide a concise task title, owner, due date and priority for Accounts approval.

Read the transcript
  1. Enter a concise title that makes sense without opening the task.
  2. Add an optional job reference to connect the request to a job card.
  3. Choose the person responsible for completing or managing the work.
  4. Set a due date and choose a priority that reflects the work.
  5. Review the request. A submitted task stays pending until Accounts approves it.
  6. The training example leaves the Submit task request button untouched.

Calendar request

Choose a Dashboard calendar date, then request an event or absence for review.

Read the transcript
  1. Open the Dashboard calendar and choose an upcoming date for the request.
  2. Choose Request time off in the day actions. The request form opens with the selected date.
  3. Enter a clear title and choose the event type, such as Training, Holiday, Sick Day or General.
  4. Add the context Accounts needs to review the request.
  5. Review the details. Requests remain pending until Accounts approves them for Outlook publication.
  6. The training example leaves the Submit request button untouched.

Timesheet audit

Open the checker from Weekly Timesheet Entry to compare a source file with its calculated results.

Read the transcript
  1. From Weekly Timesheet Entry, open Analyse or upload an existing timesheet, then choose Open timesheet analysis.
  2. Select supported source files: DOCX, DOCM, XLSX, XLS, CSV, TXT, PDF or ZIP. Convert legacy DOC files to DOCX or DOCM before automatic checking.
  3. Select a supported source file. Selecting it adds it to the list automatically; confirm it appears, then choose Calculate and check sources.
  4. Read the decision first: no action needed, issues to review or parse errors.
  5. Review correction cards and detailed rows before downloading or submitting anything. The checker does not silently change a source file.
  6. The video uses a one-row synthetic fixture labelled TRAINING ONLY, not payroll history. It does not download an export or submit an audit.
